Canonical repository for reusable Codex/OpenAI skills maintained by CNalks.

## Included

- `hybrid-file-organizer`: hybrid file organization workflow with inventory, targeted content sampling, Chinese-friendly renaming, and confirmation gates for risky operations.
- `frontend-engineer`: frontend engineering skill covering architecture, React/Next.js, Vue, Tailwind, shadcn/ui, state/data flow, accessibility, performance and testing.
- `product-designer`: product and UX design skill covering goals, user tasks, IA, flows, design systems, wireframes, visual languages and design review.

## Repository consolidation

On 2026-09-10, `frontend-engineer/` and `product-designer/` were migrated byte-for-byte from `CNalks/product-design-frontend-skills` into this canonical repository. Their Git subtree SHAs were preserved during migration.

Source repository: `CNalks/product-design-frontend-skills`

After this consolidation, new development for these skills should occur here rather than in the source repository.
